# Student Class Example in Python

## 📌 Project Description

This project demonstrates the use of classes and objects in Python through a simple Student example. It defines a `Student` class with attributes for name, roll number, and marks. An object is created using sample student data, and its details are displayed on the console.

## ✨ Features

- Defines a `Student` class using the `class` keyword.
- Uses the `__init__()` constructor to initialize student attributes.
- Stores student name, roll number, and marks.
- Creates a student object with sample data.
- Displays student details in a readable format.
- Formats marks to one decimal place.

## 🛠️ Requirements

- Python 3.x

## 📥 Installation

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

   ```bash
   cd <your-repository-folder>
   ```

## ▶️ Usage

Run the program from the terminal using:

```bash
python struct.py
```


The program creates a `Student` object with predefined details and prints the student's name, roll number, and marks.
